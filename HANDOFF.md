### The 7 Automatic Fixes Applied (in order)

These are applied by `make-clean-migration.py` whenever the clean migration is regenerated:

**Fix #1: Extensions** - Lines 24-27
- Added `CREATE EXTENSION IF NOT EXISTS` for four critical extensions
- Supabase requires these explicitly: uuid-ossp, pgcrypto, vector, pg_trgm
- Original migration assumed they existed
- This fix adds them at the very beginning

**Fix #2: hstore → jsonb** - Multiple locations
- Original uses `each(hstore(NEW) - hstore(OLD))` in trigger functions
- Supabase does NOT have hstore extension
- Replaced with jsonb_each approach
- Example: audit trigger for delta tracking now uses jsonb_each instead

**Fix #3: users.org_id column reference** - Line 1094 in error_logs triggers
- Core tables (users, organizations, invoices) use `organization_id` as tenant column
- Diamond tables use `org_id` as tenant column
- In error_logs table, a trigger was trying to write `error_logs.org_id` but referencing `users.org_id` (doesn't exist)
- Changed to: `users.organization_id::TEXT = error_logs.org_id` (cast to match)

**Fix #4: Helper functions** - After users table (lines 140-239)
- Added three helper functions for RLS policies:
  - `get_current_user_org()` - Returns current user's org_id
  - `get_current_user_role()` - Returns current user's role
  - `is_org_admin()` - Checks if user is org admin
- These are referenced by RLS policies later in the migration

**Fix #5: Missing tables** - Before Diamond tier section
- Added three tables missing from original concatenation: `providers`, `contracts`, `chargebacks`
- These are referenced by Diamond tier features
- Without them, foreign key constraints fail

**Fix #6: Transaction wrappers** - Lines 9, 7178, 7184
- Original had `BEGIN;` and `COMMIT;` at start/end
- Supabase SQL Editor auto-wraps every statement in a transaction
- Removed these to avoid double-wrapping errors
- Left as comments for reference

**Fix #7: Duplicate table definitions** - Two locations
- `dispute_predictions` defined twice (should be IF NOT EXISTS on second)
- `blockchain_anchors` defined twice (should be IF NOT EXISTS on second)
- These needed idempotency markers for re-runs
