# GAP #14: Gateway Page Request Feed is Simulated — SOLUTION

**Status:** IMPLEMENTED
**Date:** February 7, 2026
**Severity:** LOW

---

## Problem Statement

The `/gateway` page used `setInterval` (every 2-4 seconds) to inject fake requests generated by `generateRequest()` — random providers from `DEMO_PROVIDERS`, random models, random tokens/costs. Even when real metrics and analytics loaded successfully, the "Live Request Feed" always showed fabricated data. The Provider Status table also initialized with 5 hardcoded `DEMO_PROVIDERS` entries.

## Solution

Frontend-only fix. The `/v1/usage-logs` endpoint and `getUsageLogs()` API client already existed and return real per-request data (provider, model, tokens, cost, cost center, timestamp).

### Changes Made

#### `dashboard/src/app/gateway/page.tsx`

**Removed:**
- `DEMO_PROVIDERS` array (5 hardcoded providers)
- `generateRequest()` function (random fake request generator)
- `models` and `costCenters` constants (used only by `generateRequest()`)
- `setInterval` that injected fake requests every 2-4 seconds
- `DEMO_PROVIDERS` fallback in metrics fetch error handler

**Added:**
- `mapLogToRequest()` — maps API usage log entries to `LiveRequest` format, handling both camelCase and snake_case field names
- Real feed: calls `getUsageLogs({ limit: 20 })` on mount
- Polling: fetches new entries every 15 seconds, deduplicates by ID, keeps latest 20
- `providerColors` expanded with lowercase variants for API compatibility
- `feedLoading` state for loading spinner during initial feed fetch
- Empty state: "Requests will appear here as they flow through the gateway" when no data; "No requests match the selected filter" when filtered to zero
- Dynamic filter buttons derived from actual provider names in the data
- Provider table conditionally rendered (hidden when no provider data)
- Provider stats (`avgLatency`, `avgErrorRate`) safely handle empty arrays

**Preserved:**
- Real metrics fetch via `api.getMetrics(24)` + `api.getAnalytics(7)` with 30-second refresh
- Provider Status table layout and animations
- Stats grid (Total Requests, Latency p50/p95, Error Rate)
- Gateway Endpoint section with copy button
- Quick Links section
- All motion animations
