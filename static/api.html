Introduction

The Finault API allows you to programmatically allocate AI invoices, generate Close Packs, and manage allocation rules. Use it to integrate Finault into your existing FinOps workflows.

📍 Base URL

https://api.finault.ai/v1

All API requests must be made over HTTPS. Requests made over HTTP will be rejected.

Authentication

Authenticate your API requests by including your API key in the Authorization header:

Authorization: Bearer fsk_live_xxxxxxxxxxxxxxxxxxxx

You can generate API keys from your dashboard settings. Keep your API keys secure and never expose them in client-side code.

⚠️ Security

Never commit API keys to version control or expose them in browser-side JavaScript.

Rate Limits

API requests are rate limited based on your plan:

Plan Requests/Minute Requests/Day
Pro 60 1,000
Business 300 10,000
Enterprise Custom Custom

Rate limit headers are included in every response:

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 58
X-RateLimit-Reset: 1706299200

Allocate Invoice

Upload an AI provider invoice and receive allocated cost data.

POST /v1/allocate

Request Body

Parameter Type Description
file required file CSV invoice file from OpenAI, Anthropic, Azure, or Google
provider optional string Provider hint: openai, anthropic, azure, google. Auto-detected if not provided.
period optional string Period in YYYY-MM format. Defaults to current month.

Example Request

# Upload and allocate an invoice
curl -X POST https://api.finault.ai/v1/allocate \
  -H "Authorization: Bearer fsk_live_xxx" \
  -F "file=@openai-invoice-2026-01.csv" \
  -F "period=2026-01"

Generate Close Pack

Generate a complete Close Pack (Executive Summary, Journal Entry, Certificate) from an allocation.

POST /v1/close-pack

Request Body

Parameter Type Description
allocation_id required string The allocation ID from a previous /allocate call
format optional string Export format: zip (default), pdf, json
journal_format optional string Journal entry format: netsuite, quickbooks, xero, generic

Example Request

curl -X POST https://api.finault.ai/v1/close-pack \
  -H "Authorization: Bearer fsk_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{"allocation_id": "alloc_abc123", "journal_format": "netsuite"}'

Response

Returns a ZIP file containing:

  • 00-EXECUTIVE-SUMMARY.pdf
  • 01-JOURNAL-ENTRY.csv
  • 02-RECONCILIATION-CERTIFICATE.txt
  • 03-EXCEPTIONS-LOG.csv

Allocation Rules

Manage your allocation rules programmatically.

GET /v1/rules

List all allocation rules for your organization.

POST /v1/rules

Request Body

{
  "name": "Platform Team API Keys",
  "match_type": "prefix",
  "match_field": "api_key_id",
  "match_pattern": "sk-proj-platform",
  "cost_center_code": "ENG-001",
  "priority": 10
}
DELETE /v1/rules/{rule_id}

Delete an allocation rule.

Upload History

Retrieve your allocation history.

GET /v1/history

Query Parameters

Parameter Type Description
limit integer Number of results (default: 20, max: 100)
offset integer Pagination offset
period string Filter by period (YYYY-MM)
provider string Filter by provider
