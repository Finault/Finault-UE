How We Measure

Measurement Details

Our benchmark methodology is transparent and reproducible. We run 50 consecutive requests to each production endpoint and measure the complete round-trip latency using curl's timing breakdowns.

  • 50 requests per endpoint, sequential
  • Measured from US East region
  • Includes DNS, TCP, TLS, and API time
  • Real production gateway, not isolated testing
  • Percentile-based analysis (P50, P95, P99)

Benchmark Command

curl -w '%{time_total}' \ https://api.finault.ai/v1/health # Timing breakdown: # time_namelookup - DNS lookup # time_connect - TCP connection # time_appconnect - TLS handshake # time_starttransfer - First byte # time_total - Complete request
