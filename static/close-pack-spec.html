closepack.json v1.0

The Open Standard for AI Financial Close

A machine-readable JSON manifest in every Close Pack. ERPs ingest it. Auditors verify it. Your code validates it.

Why closepack.json

PDFs are for humans. JSON is for systems.

Every Close Pack now includes a structured manifest that accounting software, audit tools, and FinOps platforms can consume directly.

ERP Import

NetSuite, Xero, QuickBooks, and Sage can ingest journal entries directly from the JSON. No rekeying. No CSV wrangling. Auto-post to your GL.

Audit Verification

SHA-256 hash chain seals every line item, journal entry, and file in the pack. Auditors can verify integrity without opening a single document.

Webhook Delivery

Configure a webhook and Finault POSTs the closepack.json to your endpoint when a pack is generated. Push it into Slack, Zapier, or your ERP automatically.

Schema Reference

Six sections. One file.

The closepack.json schema is versioned and designed for backward-compatible evolution. All fields below are present in every Close Pack.

metadata
Identity and provenance of this Close Pack.
FieldTypeDescription
certIdstringUnique certificate ID (e.g. FIN-2026-01-A7B3C9) REQUIRED
periodstringAccounting period in YYYY-MM format REQUIRED
companystringOrganization name REQUIRED
generatedAtstringISO 8601 timestamp of generation REQUIRED
generatorstringGenerator identifier (e.g. finault-closepack-v2)
dataHashstringSHA-256 hash of the source invoice data REQUIRED
summary
Aggregate totals for the period.
FieldTypeDescription
totalSpendnumberTotal AI spend in USD REQUIRED
totalTokensintegerTotal tokens consumed (input + output) REQUIRED
lineItemCountintegerNumber of invoice line items
providerCountintegerDistinct AI providers
modelCountintegerDistinct models used
currencystringISO 4217 currency code (default: USD) REQUIRED
line_items[]
Every invoice line item with full cost attribution.
FieldTypeDescription
datestringUsage date (YYYY-MM-DD) REQUIRED
providerstringAI provider (openai, anthropic, google, azure, bedrock) REQUIRED
modelstringModel identifier REQUIRED
inputTokensintegerInput/prompt tokens
outputTokensintegerOutput/completion tokens
costnumberCost in USD REQUIRED
costCenterstringCost center or department
projectstringProject or feature tag
journal_entries[]
GL-ready debit/credit pairs for your accounting system.
FieldTypeDescription
datestringJournal entry date REQUIRED
accountstringGL account code REQUIRED
debitnumberDebit amount (0 if credit)
creditnumberCredit amount (0 if debit)
memostringDescription (e.g. "AI Spend - OpenAI - Engineering")
costCenterstringMapped cost center
periodstringAccounting period (YYYY-MM)
hashes
Cryptographic integrity chain for tamper detection.
FieldTypeDescription
dataHashstringSHA-256 of the source invoice data REQUIRED
manifestHashstringSHA-256 of this JSON (with this field zeroed) REQUIRED
files[]arrayPer-file hashes: { name, hash } for each document in the ZIP
compliance
FinOps compliance and health metrics.
FieldTypeDescription
focusVersionstringFinOps FOCUS spec version (e.g. 1.3)
finaultHealthScoreintegerFinancial Control Score (0-100)
anomalyCountintegerNumber of anomalies flagged
controlsRatingstringInternal controls assessment (effective, needs_improvement, ineffective)

Validator

Validate a closepack.json

Paste a closepack.json to check required fields and schema compliance. Runs entirely in your browser.

POST /v1/closepack/validate
Programmatic validation with hash integrity verification. Public endpoint — no authentication required. Send the closepack.json as the request body. 
# Validate a closepack.json via API
curl -X POST https://api.finault.ai/v1/closepack/validate \
  -H "Content-Type: application/json" \
  -d @00-CLOSEPACK.json

# Response
{
  "valid": true,
  "errors": [],
  "warnings": ["2 files missing from hashes.files"],
  "metadata": {
    "certId": "FIN-2026-01-A7B3C9",
    "period": "2026-01",
    "version": "1.0"
  }
}
