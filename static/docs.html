Developer Quickstart

Go from zero to seeing your AI costs in under 10 minutes. Three steps: get a key, point your traffic, see costs.

Don't write code yet? Upload an invoice and see results in 60 seconds. No signup required.

1 Get your API key 2 min

Sign up at app.finault.ai and copy your API key from the dashboard. Keys are scoped to your organization and track per-key usage automatically.

# Your key lives in the dashboard under Settings > API Keys
export FINAULT_API_KEY="fin_live_xxxxxxxxxxxx"
Key PrefixEnvironmentBilling
fin_live_ProductionReal usage tracked
fin_test_SandboxNo charges, full API
2 Route traffic through the gateway 5 min

Change one environment variable. Your existing OpenAI, Anthropic, or Azure code works without modification — the gateway proxies to the upstream provider and tracks every token, cost, and latency metric automatically.

# Route OpenAI traffic through Finault
curl https://gateway.finault.ai/v1/chat/completions \
  -H "Authorization: Bearer fin_live_xxx" \
  -H "X-Cost-Center: ENG-001" \
  -H "X-Provider-Key: sk-proj-xxx" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

Core Concepts

Gateway

A transparent proxy that sits between your application and AI providers. Every request is logged with token counts, latency, cost, and attribution metadata. Your existing provider SDKs work unmodified — just change the base URL.

Cost Centers

Organizational units (teams, projects, departments) that consume AI resources. Pass a cost center via the X-Cost-Center header or the SDK's costCenter parameter. Costs are attributed automatically.

Close Packs

Finance-ready audit packages generated at period end. Each pack includes an executive summary, journal entries for your ERP, a reconciliation certificate with SHA-256 hash verification, and an optional blockchain anchor for immutable proof.

Constitutional Governance

Four principles enforced on every transaction: Immutability (INSERT-only operations, nothing is ever mutated or deleted), Determinism (identical inputs produce identical outputs), Audit Survivability (every pack includes a manifest and certificate of authenticity), and Finality (completed transactions are anchored to Ethereum and posted to your ERP).

Add optional headers to enrich cost attribution. These headers are stripped before forwarding to the upstream provider.

Budget Enforcement

Set hard or soft spend limits by team, project, or time period. Budgets are enforced at the gateway level — overspend is physically prevented, not just reported.

Three Escalation Tiers

TierTriggerAction
Soft AlertConfigurable threshold (default 80%)Webhook notification, email alert, Slack message
ThrottleConfigurable threshold (default 95%)Downgrades to cheaper models automatically
Hard Cap100% of budgetReturns HTTP 402 — no request passes
 
# Create a budget
curl -X POST https://gateway.finault.ai/v1/budgets \
  -H "Authorization: Bearer fin_live_xxx" \
  -d '{
    "name": "Platform Team Monthly",
    "cost_center": "ENG-001",
    "limit": 50000,
    "period": "monthly",
    "alert_threshold": 0.8,
    "throttle_threshold": 0.95,
    "hard_cap": true
  }'

Close Packs

Generate an audit-ready close pack for any period. Each pack is a sealed ZIP containing everything your finance team needs to close the books on AI spend.

What's Inside

DocumentFormatPurpose
Executive SummaryPDFCFO-ready spend overview with trends and anomalies
Journal EntriesCSVImport-ready entries for your ERP (SAP, NetSuite, Xero, QuickBooks)
Reconciliation CertificatePDFThree-way match with SHA-256 hash verification
Controls NarrativePDFSOX-compliant control documentation
Certificate of AuthenticityJSONCryptographic proof with optional blockchain anchor
ManifestJSONComplete metadata, file inventory, and validation results
 
# Generate a close pack
curl -X POST https://gateway.finault.ai/v1/closepack \
  -H "Authorization: Bearer fin_live_xxx" \
  -F "files=@openai-jan.csv" \
  -F "files=@anthropic-jan.csv" \
  -o close-pack-jan-2026.zip

# Or generate from gateway data (no invoice upload needed)
curl -X POST https://gateway.finault.ai/v1/closepack/generate \
  -H "Authorization: Bearer fin_live_xxx" \
  -d '{ "period": "2026-01", "anchor_blockchain": true }' \
  -o close-pack-jan-2026.zip

Verification

Verify the integrity of any close pack against its sealed artifacts. The verification service runs independently from the main platform — it cannot be influenced by the system that generated the pack.

# Verify a close pack
curl -X POST https://gateway.finault.ai/v1/verify \
  -F "zip=@close-pack-jan-2026.zip"

# Response
{
  "result": "VERIFIED",
  "close_id": "FIN-CL-20260131-A7B3",
  "checks_passed": 6,
  "checks_failed": 0,
  "blockchain_anchor": "0x4a3b...c8f1",
  "tamper_detected": false
}

A web-based verification tool is also available for non-technical users.

Anomaly Detection

Four statistical methods (Z-score, IQR, EWMA, CUSUM) run continuously on your gateway traffic. Anomalies activate automatically after 24 hours of baseline data.

Anomaly Types

TypeDescription
Cost SpikeSingle request or batch exceeds 3σ of historical average
Volume SpikeRequest count jumps outside normal patterns
Unusual ModelTraffic to a model not in the normal rotation
Off-HoursSignificant activity outside business hours
Rate AnomalyPer-token cost deviates from provider rate card
Cost DropUnexplained decrease (may indicate broken pipeline)
 
# List recent anomalies
curl https://gateway.finault.ai/v1/anomalies \

Reconciliation

Three-way matching compares your usage telemetry (gateway data), provider rate cards, and invoiced amounts. Variances beyond a configurable threshold (default 2%) are flagged automatically.

# Run reconciliation for a period
curl -X POST https://gateway.finault.ai/v1/reconcile \
  -H "Authorization: Bearer fin_live_xxx" \
  -F "invoice=@openai-jan-2026.csv" \
  -d "period=2026-01"

# Response
{
  "status": "completed",
  "match_rate": 0.987,
  "total_invoiced": 23847.91,
  "total_metered": 23612.44,
  "variance": 235.47,
  "variance_pct": 0.99,
  "discrepancies": 3,
  "within_threshold": true
}

Authentication

All API requests require a Finault API key. Pass it as a Bearer token in the Authorization header or via the X-Finault-Key header.

# Option A: Authorization header
Authorization: Bearer fin_live_xxxxxxxxxxxx

# Option B: Custom header
X-Finault-Key: fin_live_xxxxxxxxxxxx

Enterprise deployments support SSO via SAML and OIDC with four access roles: admin, finance, analyst, and viewer.

API Endpoints

Base URL: https://gateway.finault.ai

Gateway

POST /v1/chat/completions

Proxy to any provider's chat API with cost tracking.

GET /v1/usage

Real-time usage and cost metrics. Filter by cost center, project, model, or time period.

Invoices

POST /v1/invoices/analyze

Upload and parse an invoice. Returns detected provider, line items, and anomalies.

POST /v1/invoices/allocate

Run cost allocation on analyzed invoice data using your allocation rules.

Close Packs

POST /v1/closepack

Generate a close pack from uploaded invoices.

POST /v1/closepack/generate

Generate a close pack from gateway data (no invoice upload needed).

GET /v1/closepack/{close_id}

Download a previously generated close pack.

Intelligence

GET /v1/anomalies

List detected anomalies. Filter by severity, type, cost center.

POST /v1/reconcile

Run three-way reconciliation between gateway data, rate cards, and invoices.

POST /v1/verify

Verify close pack integrity against sealed artifacts.

Budgets

POST /v1/budgets

Create a budget with alert thresholds and hard caps.

GET /v1/budgets

List all budgets and their current utilization.

GET /v1/budgets/{budget_id}

Get budget details including spend history and alerts.
