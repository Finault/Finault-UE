Developer Documentation

Welcome to Finault's developer documentation. Learn how to integrate with our API to proxy AI requests through multiple providers, track costs, and optimize your AI spending. Get up and running in minutes.

2

Get Your API Key

Sign up or log in to get your unique API key for authenticated requests.

  1. Visit finault.ai/login
  2. Sign up with your email or log in
  3. Navigate to finault.ai/welcome
  4. Copy your API key (starts with fk_live_ for production)

Tip: Keep this key secret. Never commit it to version control. Use environment variables or secrets management.

3

Make Your First Proxied Request

Send a chat completion request through Finault to OpenAI, Anthropic, or any supported provider.

bash 
curl -X POST https://api.finault.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer fk_live_xxxxx" \
  -H "X-Provider-Key: sk-openai-xxxxx" \
  -d {
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "What is the capital of France?"}
    ],
    "max_tokens": 100
  }'

Error Handling with Retry:

bash 
#!/bin/bash

function call_finault() {
  local retry_count=0
  local max_retries=3

  while [ $retry_count -lt $max_retries ]; do
    response=$(curl -s -w "\n%{http_code}" \
      -X POST https://api.finault.ai/v1/chat/completions \
      -H "Content-Type: application/json" \
      -H "Authorization: Bearer $FINAULT_API_KEY" \
      -H "X-Provider-Key: $OPENAI_API_KEY" \
      -d '{
        "model": "gpt-4o",
        "messages": [{"role": "user", "content": "Hello"}]
      }')

    http_code=$(echo "$response" | tail -n1)
    body=$(echo "$response" | sed '$ d')

    if [ $http_code -eq 200 ]; then
      echo "$body"
      return 0
    elif [ $http_code -eq 429 ]; then
      retry_count=$((retry_count + 1))
      sleep $((2 ** retry_count))
    else
      echo "Error: $http_code" >&2
      return 1
    fi
  done
}

With Cost Center & Error Handling:

python 
import requests
import time
from typing import Optional

def call_finault(
    prompt: str,
    cost_center: Optional[str] = None,
    max_retries: int = 3
) -> dict:
    """Call Finault API with automatic retry on rate limit."""

    headers = {
        "Authorization": f"Bearer {os.getenv('FINAULT_API_KEY')}",
        "X-Provider-Key": os.getenv("OPENAI_API_KEY"),
        "Content-Type": "application/json"
    }

    if cost_center:
        headers["X-Finault-Cost-Center"] = cost_center

    payload = {
        "model": "gpt-4o",
        "messages": [{"role": "user", "content": prompt}],
        "max_tokens": 500
    }

    for attempt in range(max_retries):
        try:
            response = requests.post(
                "https://api.finault.ai/v1/chat/completions",
                headers=headers,
                json=payload,
                timeout=30
            )

            if response.status_code == 429:
                wait_time = int(response.headers.get("Retry-After", 2 ** attempt))
                time.sleep(wait_time)
                continue

            response.raise_for_status()
            return response.json()

        except requests.exceptions.RequestException as e:
            if attempt == max_retries - 1:
                raise
            time.sleep(2 ** attempt)

    return {}

# Usage
result = call_finault("What is AI?", cost_center="research-team")
print(result["choices"][0]["message"]["content"])

With Error Handling & Retry:

javascript 
async function callFinaultWithRetry(
  prompt,
  costCenter = null,
  maxRetries = 3
) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      const headers = {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${process.env.FINAULT_API_KEY}`,
        "X-Provider-Key": process.env.OPENAI_API_KEY
      };

      if (costCenter) {
        headers["X-Finault-Cost-Center"] = costCenter;
      }

      const response = await fetch("https://api.finault.ai/v1/chat/completions", {
        method: "POST",
        headers,
        body: JSON.stringify({
          model: "gpt-4o",
          messages: [{ role: "user", content: prompt }],
          max_tokens: 500
        })
      });

      if (response.status === 429) {
        const retryAfter = parseInt(response.headers.get("retry-after") || 2 ** attempt);
        await new Promise(r => setTimeout(r, retryAfter * 1000));
        continue;
      }

      if (!response.ok) {
        throw new Error(`API error: ${response.status}`);
      }

      return await response.json();
    } catch (error) {
      if (attempt === maxRetries - 1) throw error;
      await new Promise(r => setTimeout(r, 2 ** attempt * 1000));
    }
  }
}

// Usage
const result = await callFinaultWithRetry("What is ML?", "research-team");
console.log(result.choices[0].message.content);

Go

Simple Request:

go 
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
    "os"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-4o",
        "messages": []map[string]string{
            {"role": "user", "content": "Hello"},
        },
        "max_tokens": 100,
    }

    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST",
        "https://api.finault.ai/v1/chat/completions",
        bytes.NewBuffer(body))

    req.Header.Set("Content-Type", "application/json")
    req.Header.Set("Authorization",
        fmt.Sprintf("Bearer %s", os.Getenv("FINAULT_API_KEY")))
    req.Header.Set("X-Provider-Key",
        os.Getenv("OPENAI_API_KEY"))

    client := &http.Client{}
    resp, _ := client.Do(req)

    // Cost in headers
    cost := resp.Header.Get("X-Finault-Cost-Dollars")
    fmt.Printf("Cost: $%s\n", cost)
}

ruby 
def call_finault_with_retry(prompt, cost_center = nil, max_retries = 3)
  headers = {
    'Content-Type' => 'application/json',
    'Authorization' => "Bearer #{ENV['FINAULT_API_KEY']}",
    'X-Provider-Key' => ENV['OPENAI_API_KEY']
  }
  headers['X-Finault-Cost-Center'] = cost_center if cost_center

  max_retries.times do |attempt|
    begin
      response = HTTParty.post(
        'https://api.finault.ai/v1/chat/completions',
        headers: headers,
        body: {
          model: 'gpt-4o',
          messages: [{ role: 'user', content: prompt }],
          max_tokens: 500
        }.to_json
      )

      if response.code == 429
        wait_time = (response.headers['Retry-After'] || 2 ** attempt).to_i
        sleep(wait_time)
        next
      end

      return response if response.success?
    rescue => e
      raise e if attempt == max_retries - 1
      sleep(2 ** attempt)
    end
  end
end

Error Reference

Complete guide to error codes and how to resolve them.

Code Status Meaning How to Fix
AUTH_FAILED 401 Invalid or missing Finault API key Verify your key starts with fk_live_ or fk_test_ and is not expired. Regenerate at finault.ai/welcome if needed.
PROVIDER_KEY_INVALID 401 Invalid provider API key (OpenAI, Anthropic, etc.) Check that your provider key is correct and passed in X-Provider-Key header. Ensure it's not expired.
TOKEN_REVOKED 401 API key has been revoked by admin Generate a new API key at finault.ai/welcome
IP_NOT_ALLOWED 403 Your IP is not in organization allowlist Add your IP to the security settings at finault.ai/dashboard → Settings → IP Allowlist
RATE_LIMIT_EXCEEDED 429 Organization or account rate limit exceeded Wait for Retry-After seconds before retrying. Implement exponential backoff. Upgrade plan for higher limits.
QUOTA_EXCEEDED 429 Monthly token or spending quota exceeded View limits at finault.ai/dashboard → Quotas. Request increase or wait for quota reset on the 1st of next month.
VALIDATION_ERROR 400 Request body is invalid (missing fields, wrong format) Check required fields in API reference. Validate JSON schema. See error details in response body.
INVALID_MODEL 400 Model is not supported or not enabled Check available models at finault.ai/pricing or via GET /v1/pricing. Enable in dashboard if available.
PROVIDER_ERROR 502 Upstream AI provider (OpenAI, Anthropic, etc.) returned error Check provider status. Retry with exponential backoff. Error details available in response body.
PROVIDER_TIMEOUT 502 Provider took too long to respond Retry the request. Consider using router for failover to faster provider.
SERVICE_UNAVAILABLE 503 Finault service temporarily unavailable Check finault.ai/status. Implement retry logic with exponential backoff.
SESSION_INVALIDATED 401 All sessions invalidated (security event) Re-authenticate. Generate new API key at finault.ai/welcome

Common Authentication Errors

401 Unauthorized: Missing or Invalid API Key

This error occurs when your Finault API key is missing, invalid, or expired.

Solution: Verify you're passing the Authorization: Bearer fk_live_... header. Check the key hasn't been revoked. Generate a new key at finault.ai/welcome if needed.

Rate Limiting

Finault enforces rate limits to ensure fair usage. When you hit a limit, you'll receive a 429 status with a Retry-After header.

http 
HTTP/1.1 429 Too Many Requests
Retry-After: 60
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 1740506635

{
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "Organization rate limit exceeded. Retry after 60 seconds."
  }
}

Always implement exponential backoff in your client. Wait for the Retry-After header value before retrying. Upgrade your plan for higher rate limits.

Provider Errors

When the upstream provider (OpenAI, Anthropic, Google, etc.) returns an error, Finault passes it through with additional context.

json 
{
  "error": {
    "code": "PROVIDER_ERROR",
    "message": "OpenAI API error",
    "provider": "openai",
    "provider_error": {
      "code": "invalid_request_error",
      "message": "Tokens per minute limit exceeded",
      "type": "invalid_request_error"
    }
  },
  "request_id": "req_xyz789abc123"
}

Check the provider_error field for details. Common issues: expired provider key, insufficient balance, rate limit on provider side, or unsupported parameters. Use the intelligent router to automatically failover to another provider on error.

CLI

Finault CLI

Auto-fetch AI usage from your providers and push it to Finault — from your terminal. Set it up once, run it automatically every month. No more manual CSV exports.

What the CLI does

The finault command connects to your AI provider APIs (OpenAI, Anthropic, AWS Bedrock), pulls last month's usage data, normalizes it into Finault's standard CSV format, and uploads it to your Finault dashboard. It stores a sync log locally so you can see month-over-month trends, and optionally sends a Slack notification with a cost summary after every sync.

The CLI requires requests (installed automatically). For AWS Bedrock, you'll also need boto3: pip install boto3

Your First Sync — 3 Minutes

Go from zero to synced in three commands.

1

Initialize with your provider

This creates a .finault/config.json in your project and auto-adds it to .gitignore.

bash 
finault init --provider openai --finault-key fk_live_your_key

You'll be prompted for your provider API key if not passed via --api-key or $OPENAI_API_KEY.

2

Pull last month's usage

Fetches usage data from all configured providers, generates a CSV, saves it locally, and uploads to Finault.

bash 
finault sync

Output:

3

Open your dashboard

Head to app.finault.ai to see your cost breakdown, Bessemer tier classification, model-level analysis, and downloadable Close Pack for your board.

Automate Monthly Syncs

Set it and forget it. The CLI shows you the exact cron line or GitHub Actions config:

bash 
finault cron

Option A: Crontab

bash 
# Add to crontab (crontab -e)
# Runs on the 2nd of every month at 9am
0 9 2 * * cd /path/to/project && finault sync >> .finault/sync.log 2>&1

Option B: GitHub Actions

yaml 
# .github/workflows/finault-sync.yml
name: Finault Cost Sync
on:
  schedule:
    - cron: '0 9 2 * *'
jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
      - run: pip install finault
      - run: finault sync
        env:
          FINAULT_API_KEY: ${{ secrets.FINAULT_API_KEY }}
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}

Slack Notifications

Add --slack-webhook during finault init and every sync will post a summary to your Slack channel — total spend, record count, month-over-month change, and a link to your dashboard.

finault init

Initialize Finault sync in the current project. Creates .finault/config.json and auto-adds it to .gitignore.

bash 
finault init [OPTIONS]
FlagDescriptionRequired
--provider AI provider to sync: openai, anthropic, aws, google, azure No (prompted if omitted)
--api-key Provider API key. Also reads $OPENAI_API_KEY, $ANTHROPIC_API_KEY, etc. No (prompted if omitted)
--finault-key Your Finault API key (fk_...). Also reads $FINAULT_API_KEY. No (prompted if omitted)
--slack-webhook Slack Incoming Webhook URL for monthly sync notifications. No

Examples

bash 
# Basic setup with OpenAI
finault init --provider openai --finault-key fk_live_abc123

# Add Anthropic as a second provider
finault init --provider anthropic --api-key sk-ant-...

# With Slack notifications
finault init --provider openai --slack-webhook https://hooks.slack.com/services/T.../B.../xxx

# Using environment variables (no flags needed)
export FINAULT_API_KEY=fk_live_abc123
export OPENAI_API_KEY=sk-...
finault init --provider openai

Config location: .finault/config.json in your project root. Contains API keys — auto-added to .gitignore to prevent accidental commits.

finault sync

Fetch usage data from all configured providers, generate a CSV, save it locally, and upload to Finault. Sends a Slack notification if configured.

bash 
finault sync [OPTIONS]
FlagDescriptionDefault
--period Month to sync, in YYYY-MM format. Previous month
--finault-key Override the stored Finault API key. From config or $FINAULT_API_KEY

Examples

bash 
# Sync previous month (default)
finault sync

# Sync a specific month
finault sync --period 2026-01

# Backfill the last 6 months
for m in 09 10 11 12 01 02; do finault sync --period 2025-$m; done

What happens

1. Connects to each provider API (OpenAI, Anthropic, AWS) using stored keys
2. Pulls usage data for the period, grouped by model and project
3. Normalizes into Finault's 10-column CSV format
4. Saves CSV to .finault/finault-sync-YYYY-MM.csv
5. Uploads to Finault's ingest API
6. Records sync in local log (last 12 months retained)
7. Sends Slack notification with spend summary and month-over-month change

finault ingest

Import a CSV from any provider — even formats Finault has never seen. The fuzzy column matcher auto-detects your columns and maps them to Finault's standard format.

bash 
finault ingest <file> [OPTIONS]
Argument / FlagDescriptionRequired
file Path to your CSV or TSV file. Yes
--finault-key Override the stored Finault API key. No

Examples

bash 
# Import an AWS Cost Explorer export
finault ingest aws-bedrock-feb.csv

# Import a custom internal billing file
finault ingest internal-ai-costs.tsv

# Any format works — Finault auto-detects columns
finault ingest vendor-invoice.csv

How column detection works

The fuzzy matcher reads your CSV headers and maps them to Finault's 10 standard fields. For example, charge_usd maps to cost_in_usd, engine maps to model, and department maps to project_name. It handles $ signs, commas in numbers, and TSV files. If it can't find a cost column, it shows exactly what columns it found and what it expected.

Minimum required columns: cost (any alias). model is recommended but optional — without it, costs are grouped as "unknown".

Finault CSV Format

The standard 10-column format that all Finault tools produce and consume.

ColumnTypeRequiredDescription
timestampISO 8601NoWhen the usage occurred. Default: first of current month.
organization_idstringNoInternal org identifier.
organization_namestringNoHuman-readable org name.
project_idstringNoProject/workspace identifier.
project_namestringNoHuman-readable project name.
api_key_idstringNoWhich API key was used.
api_key_namestringNoHuman-readable key name.
modelstringRecommendedAI model name (e.g., gpt-4o, claude-sonnet-4-5).
usage_typestringNoinput, output, or combined.
cost_in_usdfloatYesCost in US dollars.

Custom CSV Support

Don't have Finault's exact column names? No problem. The finault ingest command auto-detects common variations:

Finault ColumnAlso Accepts
cost_in_usdcost, amount, total, spend, charge, price, usd, total_cost, billed_amount, usage_cost
modelmodel_name, model_id, llm, engine, deployment, model_version, ai_model
timestampdate, time, created_at, usage_date, billing_date, period, invoice_date
project_nameproject, workspace, team, department, cost_center, application, service
organization_nameorganization, org, company, account, tenant

The matcher also handles $ signs and commas in cost values (e.g., $1,234.56 → 1234.56), and auto-detects TSV (tab-separated) files.

Provider Export Guides

How to get your cost data out of each provider — for use with finault ingest or direct upload.

OpenAI

Best option: use finault sync --provider openai (auto-fetches via API). For manual export:

Go to platform.openai.com → Settings → Organization → Usage. Select the month, click "Export". The resulting CSV works directly with finault ingest.

Anthropic

Best option: use finault sync --provider anthropic (auto-fetches via API). For manual export:

Go to console.anthropic.com → Settings → Plans & Billing → Usage. Export the usage data. Columns like total_cost and workspace_name are auto-detected.

AWS Bedrock

Best option: use finault sync --provider aws (uses Cost Explorer API, requires boto3). For manual export:

Go to AWS Console → Cost Explorer → Filters: Service = Amazon Bedrock. Export as CSV. Columns like UnblendedCost and Service are auto-detected.

Google Vertex AI

Go to Google Cloud Console → Billing → Reports. Filter by Vertex AI / Generative AI services. Export as CSV. Columns like cost and sku.description are auto-detected.

Azure OpenAI

Go to Azure Portal → Cost Management → Cost Analysis. Filter by Azure OpenAI Service. Export as CSV. Columns like Cost and MeterCategory are auto-detected.

Any other provider?

Export your costs as a CSV with at least a cost column, then run finault ingest your-file.csv. The fuzzy column matcher handles the rest.
