Before and after

One line changes. Your AI responses are identical. But now every call is governed.

Before — ungoverned
from openai import OpenAI

client = OpenAI(
    api_key="sk-..."
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello"}]
)
# No cost tracking. No audit trail. No attribution.
After — governed by Finault
from openai import OpenAI

client = OpenAI(
    api_key="sk-...",
    base_url="https://api.finault.ai/v1",
    default_headers={"X-Finault-API-Key": "fk_..."}
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello"}]
)
# Cost tracked. Audit hash attached. GL-attributed.

Config via environment variables

Store your Finault key in your environment. Reference it in code. Clean, secure, works everywhere.

Store your key securely

Add your Finault API key to your environment or .env file. Reference it in your AI client config alongside your provider key.

FINAULT_API_KEY=fk_live_abc123def456

Works everywhere

Docker, Kubernetes, Lambda, Railway, Vercel, Heroku — anywhere you set env vars.

# Docker
ENV FINAULT_API_KEY=fk_live_abc123def456

# Kubernetes
- name: FINAULT_API_KEY
  valueFrom:
    secretKeyRef: { name: finault, key: api-key }
