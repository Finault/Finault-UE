Security & Trust

Enterprise-grade security. Zero-trust architecture.

Your financial data never touches a centralized server. Every artifact is cryptographically signed and independently verifiable.

Edge-First Architecture

All processing runs on Cloudflare Workers — 300+ global edge locations. Your CSV is parsed, reconciled, and packaged at the nearest edge node. Sub-100ms response times worldwide. No centralized server. No data at rest.

Cryptographic Integrity

Every close pack includes an HMAC-SHA256 signed manifest with SHA-256 hashes per artifact. Signing uses Web Crypto API with server-side secrets. Manifests use sorted keys for deterministic output. Any file modification breaks the signature chain.

Data Handling

CSVs are processed in-memory during the request lifecycle. No billing data is persisted after the close pack is generated. Close packs are stored in Cloudflare R2 as sealed, write-once objects. No delete operations — immutable by design.

Verification

Every close pack can be independently verified at finault.ai/verify. Upload your close pack ZIP — we recompute all SHA-256 hashes and validate the HMAC signature against our public verification endpoint. No trust required — verify yourself.
